# Summary

Rooms and the agent mesh call the kinds of work an agent takes "jobs". The Mesh adapter now reads them from `MESH_JOBS` and advertises them as `jobs` on its card. astro-server sets `MESH_JOBS` from `agent.jobs` in `astropods.yml`.

# Design

```
MESH_JOBS='[{"name":"github.issue.investigate","description":"Investigates a new GitHub issue."}]'
```

The card's jobs are the agent's identity (`agent.<name>`), then `MESH_JOBS` in order, keeping the first entry for each name. The name pattern, the reserved `agent.` prefix, and the warnings for bad entries are unchanged.

The deprecated `AgentConfig.skills` proto field and the Node SDK type keep their names for wire compatibility. They stay ignored.

# Migration

Deploy this image with the astro-server release that sets `MESH_JOBS`. A sidecar on the old image reads `MESH_SKILLS` and advertises only `agent.<name>` until it is replaced.
